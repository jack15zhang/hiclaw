# One month delivery plan

## Week 1: Foundation

- Create mobile and server projects.
- Build app shell, conversation home, listing cards, and login gate.
- Build API modules for auth, users, carpool, marketplace, agent, trust.
- Add PostgreSQL, Redis, and schema migrations.

## Week 2: Core features

- Implement carpool browse, post, nearby match, and confirm states.
- Implement marketplace browse, post, image upload placeholders, search, and contact states.
- Implement phone, Google, and Facebook login adapters.
- Add location privacy handling.

## Week 3: Agent and trust

- Route natural language requests into carpool and marketplace actions.
- Generate structured draft posts from chat.
- Track usage count, completed actions, reports, and trust level.
- Add hidden feature unlock framework.

## Week 4: Test and release

- Add API integration tests and mobile smoke tests.
- Load test browse and match endpoints.
- Fix security and privacy issues.
- Prepare TestFlight and Android internal testing release.
