# hiclaw mobile

React Native and Expo app for iPhone and Android.

## Current MVP scaffold

- Conversation-first home screen.
- Anonymous browse for carpool and marketplace cards.
- Login gate for posting, confirming, contacting, and profile actions.
- Demo agent routing for carpool and second-hand trading intents.

## Next implementation steps

- Connect browse cards to the API server.
- Add quick login screens for phone, Google, and Facebook.
- Add post flows generated from agent conversation.
- Add native push notification registration.
